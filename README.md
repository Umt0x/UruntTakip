# MediaMarkt Ürün Takip v1.3

MediaMarkt ürün kartlarında iki bağımsız durum tutulur:

- **Eklendi / Eklenmedi**
- **Fiyat Kontrol ✓ / Fiyat Kontrolü Yok**

Eklenti menüsünden ürün aramasının **Hepsiburada** veya **Trendyol** üzerinde yapılması seçilebilir. Arama sorgusunda kupon, kampanya ve fiyat satırları kullanılmaz; yalnızca ürün adı gönderilir.

## Fiyat kontrolü yönetimi

- Tüm fiyat kontrolü kayıtları tek tuşla sıfırlanabilir.
- Bu işlem **Eklendi** kayıtlarına dokunmaz.
- İsteğe bağlı olarak, fiyat kontrolü işaretleri işaretlendikleri aydan sonraki ay otomatik kaldırılabilir.

Yedek alma ve geri yükleme özellikleri korunmuştur.
